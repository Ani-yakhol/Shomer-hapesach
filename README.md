# 🔐 שומר הפתח – v0.0.10
**כלי בקרה וניהול זמן שימוש במחשב Windows**

---

## 📋 דרישות מערכת
- **Windows** 10 / 11 (64-bit)
- **Python** 3.10 ומעלה
- **הרצה כמנהל (Administrator)** — נדרש לחסימות רג'סטרי

---

## ⚡ התקנה — מחשב מחובר לאינטרנט

```cmd
pip install PyQt6 pywin32 psutil
python main.py
```

---

## 💾 התקנה — מחשב **ללא** חיבור לאינטרנט

### שלב 1 — במחשב שיש לו אינטרנט, הורד את החבילות:
```cmd
pip download PyQt6 pywin32 psutil --dest C:\shomer_packages
```

### שלב 2 — העבר את תיקיית `C:\shomer_packages` למחשב הנוכחי (USB / דיסק)

### שלב 3 — במחשב ללא אינטרנט, התקן מהתיקייה:
```cmd
pip install --no-index --find-links=C:\shomer_packages PyQt6 pywin32 psutil
```

### שלב 4 — הפעל:
```cmd
python main.py
```

## 🔑 כניסה להגדרות

- **כניסה כ"מנהל מערכת"** ← לחץ "כניסה להגדרות" במסך הכניסה

## 📦 קימפול לקובץ EXE יחיד (ללא תלויות)

### שלב 1 — התקן PyInstaller
```cmd
pip install pyinstaller
```

### שלב 2 — קמפל (הרץ מתוך תיקיית הפרויקט)
```cmd
pyinstaller --onefile --windowed --uac-admin --name="shomer-hapetach" main.py
```

**עם אייקון (אם יש קובץ icon.ico):**
```cmd
pyinstaller --onefile --windowed --uac-admin --icon=icon.ico --name="shomer-hapetach" main.py
```

**עם קבצי .reg מוטמעים:**
```cmd
pyinstaller --onefile --windowed --uac-admin --add-data "BlockACD.reg;." --add-data "UnblockACD.reg;." --name="shomer-hapetach" main.py
```

### שלב 3 — הקובץ המוכן נמצא ב:
```
dist\shomer-hapetach.exe
```

> **הערה:** הרץ תמיד כמנהל (קליק ימני → "הפעל כמנהל") לתפקוד מלא.

### קימפול במחשב ללא אינטרנט — הורד PyInstaller מראש:
```cmd
pip download pyinstaller --dest C:\pyinstaller_pkg
pip install --no-index --find-links=C:\pyinstaller_pkg pyinstaller
```

## ❓ פתרון בעיות

**"Access Denied"** → קליק ימני על main.py → "הפעל כמנהל"

**פאנל הגדרות לא נפתח** → לחץ F8 ← הקש `admin` ← Enter

**Python לא נמצא** → `python --version` בCMD — אם שגיאה, התקן שוב עם "Add to PATH"

**לא מוצג בלוק Ctrl+Alt+Del** → הרץ כמנהל ולך להגדרות → הגדרות → "החל כעת"

## 🔒 אבטחת מסכי כניסה / יציאה

### מה חסום:
- מקש Windows (LWin / RWin) + כל צירוף Win+X
- Alt+Tab, Alt+F4, Alt+Esc (מניעת מעבר חלונות)
- Ctrl+Esc (תפריט התחל), Ctrl+Shift+Esc (Task Manager)
- Ctrl+Alt+Del — נחסם דרך הרג'סטרי (דורש הרצה כמנהל)
- Print Screen, Sleep, F1–F12

### מגבלות טכניות ידועות:
| מגבלה | הסבר |
|--------|-------|
| Ctrl+Alt+Del לא נחסם ב-100% | Windows שומר מנגנון זה ברמת ה-Kernel, והחסימה דרך רג'סטרי עובדת ב-Windows 10/11 Home אך לא תמיד ב-Enterprise/Education עם Group Policy. |
| Taskbar ניתן להופיע רגעית | בחלפ מעבר חלון מהיר, שורת המשימות עלולה להבהב — החלון חוזר לקדמה תוך פחות משנייה. |
| תוכנות מסוימות עלולות לעקוף | תוכנות עם הרשאות System (גבוהות מ-Administrator) לא תסגרנה על ידי שומר הפתח. |

## 🖨️ ניטור מדפסות וחיוב

### הגדרה:
1. לשונית **מדפסות** ← סמן "מנוטר" למדפסות הרצויות ← לחץ "הגדר תעריפים"
2. הגדר תעריף לכל סוג: A4 שחל, A4 צבע, A3 שחל, A3 צבע
3. לשונית **תשלום** ← הגדר "מחיר דקת שימוש" (לניכוי מזמן כשאין חבילת הדפסות)

### אלגוריתם חיוב:
- אם למשתמש יש **חבילת הדפסות** → מנוכות עמודים מהחבילה
- אם אין חבילה → מחושב שווי כספי ומנוכות דקות שימוש מקביל

### דרישה: pywin32
```cmd
pip install pywin32
```
